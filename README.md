## Currently building

**Ein neuronales Netz, das ein Mobile-Game eigenständig spielt** — ohne offizielles API.

Ich habe eine eigene Trainingsumgebung entwickelt, in der das Modell auf simulierten Spielsituationen trainiert. Konzeption, Architektur und Trainingslogik kommen komplett von mir; für die Umsetzungsgeschwindigkeit setze ich gezielt auf **Cursor** und **Claude**.

```
game_env/          → eigene Simulationsumgebung
train.py           → Training auf generierten Spielsituationen
model/policy_net.* → Entscheidungslogik des Agents
```

Teilnehmer beim **Cursor Hackathon Frankfurt** — aktiver Austausch mit der Dev-Community rund um KI-gestützte Entwicklung.
